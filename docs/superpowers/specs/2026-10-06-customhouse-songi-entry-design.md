## 2. 사용자 흐름

1. **셀프 접수 (손님 폰)** — 부스 앞 QR → 안내 페이지 → [접수하기]
   1. 휴대폰 번호 → 인증번호 6자리(SOLAPI) → 인증
      - 이미 접수한 번호(취소 제외)면 즉시 "이미 참여하셨어요" + 본인 회차권으로 이동
   2. 개인정보 수집·이용 동의 (만 14세 미만 참여자는 대표가 법정대리인으로 동의)
   3. 영수증 금액 입력 (여러 장 추가 가능, 가게명 선택 입력) → 합계·최대 인원 즉시 표시
   4. 참여자 입력 (1~최대 인원명, 각 이름/성별/나이)
   5. 제출 → **접수 대기 화면**: 접수번호(예: `A-123`) + "데스크에 영수증을 보여주세요"
2. **데스크 승인 (접수 담당 1명, 태블릿)** — 관리자 화면 '승인 대기'에서 번호 뒤 4자리·접수번호로 검색
   - 실물 영수증 확인(당일·관내·합계) + 영수증에 "사용" 도장
   - 필요 시 금액·인원 수정 → **[승인]** → 오늘 남은 좌석 ≥ 인원인 가장 빠른 회차 자동 제안(직원이 다른 회차 선택 가능)
   - 승인 즉시: 손님 화면이 회차권으로 전환(폴링) + 회차권 문자 발송 + 10분 전 알림 예약
3. **입장 (도안 안내 담당)** — 회차권 화면(회차 색·큰 시간·인원·접수번호) 확인 → 관리자 화면 [입장] → 이후 회차권은 "입장 완료" 표시
4. **현황판** — `/board` 태블릿/TV: 오늘 회차별 남은 좌석·현재 회차 (개인정보 없음)

※ 스마트폰이 없거나 어려운 손님: 데스크 태블릿에서 직원이 대신 진행(인증번호는 손님 폰으로 수신 → 구두 확인)

## 3. 상태

`pending`(접수, 승인 전) → `approved`(회차 배정) → `checked_in`(입장) / `no_show`(노쇼 해제, 좌석 반환) / `cancelled`
- 좌석 계산 = 해당 회차 `approved`+`checked_in` 인원 합
- 1인 1회 = phone unique (status ≠ cancelled)

**③ 10분 전 알림 (SMS/LMS)**

- 회차 변경·취소·노쇼 시 예약된 ③ 취소(DELETE schedule), 변경 시 재예약
